# crossword-chat pack (local)

CrosswordChat's **residue** pack: the repo's own instances of rules the mounted canon states in
general. Declared by hand as `local/crossword-chat` in `.claudinite-settings.json`.

The judgment lives in canon. `host-page` owns guesting in a web app you do not own (the DOM
quarantine, selector nets, the probe, the fixture, synthetic input, host lifecycle states,
inertness) and ships the three checks this pack used to carry; `web-speech` owns the browser
voice surfaces and its six checks; `chrome-extension` owns how the code reaches the page. What
is left here is what no other repo could use: the `xwd__` token the arch test enforces and the
`page-adapter/` wall it guards, nytimes.com's ~30 s idle auto-pause and the bare-`Shift` nudge,
the pencil button's unreadable ON state, the measured 1.8 s pause window, the fixture and its
`localhost:8787` dev build, the `selectors.js` provenance record, and the REQ and MT ids that
carry the evidence.

**No checks.** Every check this pack's predecessors ran is now canon's, running here through the
`host-page` and `web-speech` declarations. The one repo-specific scan — the `xwd__` quarantine —
is the project's own test (`extension-test/unit/arch.test.js`), where it belongs.

**Adding to it:** a rule that reads as true of any repo belongs in canon, not here.
