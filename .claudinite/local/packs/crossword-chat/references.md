# References — rationale behind this pack's rules

Maintenance and review material for the `writing-pack-prose` references convention: each entry
carries the reason a rule exists, written so a periodic review can reaffirm — or retire — it.
Entry keys are file-scoped stable identifiers (gaps allowed, never renumbered): an end-of-line
`(n)` marker in `RULES.md` cites `RULES-n`. No session loads this file for daily work.

Every rule in this pack is an instance verified against nytimes.com or against this repo's own
tree, and each cites the file, requirement id or manual test that records it — so the evidence
is in the rule itself and needs no entry here. An entry belongs here when a rule's *reason*
outgrows its citation.
